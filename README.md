# Valo

Valo is an AI-first sales automation workspace designed to help businesses turn enquiries into paying customers.

## MVP direction

- Priority lead management
- AI-assisted lead qualification
- Follow-up workflow
- AI reply copilot
- Customer and conversation workspace
- Revenue/pipeline visibility
- Automation activity feed

## Local development

```bash
npm install
npm run dev
```

## Product principle

Valo is not intended to be a generic chatbot or generic CRM. The product should automate concrete revenue-generating workflows and keep a human in control of consequential actions.
